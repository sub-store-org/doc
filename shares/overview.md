# 分享概览

「分享」功能为订阅/组合订阅/文件生成一个**分享链接**，方便快速把数据分发给其他人或另一台设备。分享的类型（来源）可以是：

- **单条订阅**（subscription）
- **组合订阅**（collection）
- **文件**（file）

## 使用方法

1. 在订阅/文件编辑页打开分享（或从「分享」tab 新建）
2. 设置分享选项（见下方），得到一个分享链接（`/share/...`）
3. 把链接发给对方；对方打开链接即可使用对应数据（自动按请求端 UA 输出格式）

## 分享选项

创建/编辑分享时可配置：

- **过期方式**：按需选择
  - **时长**：创建后经过一段时间过期（单位可选分钟/小时/天/周/月/年等）
  - **具体时间**：到指定日期时间过期
  - **次数**：最多被使用 N 次后过期
- **Token**：自定义分享链接的访问令牌（不填写则自动生成）；分享链接形如 `/share/<token>/...`
- **显示名 / 备注 / 标签 / 图标**：便于在分享列表中识别
- **age 加密**：可配置 age 公钥，分享内容用 age 加密，对方需持有对应私钥才能解密（`age-secret-key`）
- **分享 URL 开关**：开启后才生成对外可用的分享链接

分享创建后可：

- **编辑**：调整过期时间、停止分享等
- **停用 / 恢复**、**删除（含过期分享清理）**
- **复制链接** / **导出**分享数据

## 注意事项

- 分享功能下有部分参数**禁止使用**：`fakeSub` / `fakeFile` / `url` / `content` / `mergeSources` / `subInfoUrl` 等；文件分享链接还禁止使用 `type` / `source` / `sourceType` / `sourceName` / `mode` 等运行时来源覆盖参数
- 分享链接会暴露你配置的数据，注意不要分享包含敏感信息的文件/订阅
- **设置过期时间/次数上限**可降低长期暴露风险；删除/停用分享会立即使链接失效
- 可用脚本按请求方限制分享行为，例如 UA 不符合时返回自定义状态码（见 [脚本使用 - 自定义响应](../script/usage)）
