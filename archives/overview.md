# 归档概览

「归档」用于收存**暂时不使用但不想删除**的订阅/组合订阅/文件，让主列表保持整洁。

## 用法

- 把暂时不用的订阅/组合订阅/文件（以及分享/产物）移入归档
- 归档中的条目以**快照**形式保留，不会丢失配置，需要时可以恢复回主列表
- 可用于换季清理、多机场轮换等场景，避免误删配置

## 归档与删除

归档本质上是一种 **「删除并保留快照」** 的操作：

- 归档时，条目会先从主列表（订阅 / 组合订阅 / 文件）中**移除**，同时把它的完整配置快照存进「归档」
- 因此，**已生成的输出链接（`/download/<name>`、`/api/file/<name>`）在归档后会失效**——请求不再能找到该条目
- 需要重新使用时，把条目从归档**恢复**（移回），配置与输出链接即恢复正常

::: warning 注意
如果确认某个订阅/文件不再需要，也可以选择**永久删除**（不进归档）。归档条目不参与订阅拉取与输出，恢复前其配置处于冻结状态。
:::

## 提示

- 分享/产物等条目也可归档，规则相同：归档即失效、恢复即生效
- 定期清理不再使用的归档条目，可避免数据 JSON 膨胀
